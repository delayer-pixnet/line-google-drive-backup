# 朋友綁定指南

這個 Bot 是私人使用。你會使用共同的 LINE Bot，但附件、文字與備份紀錄會放在你自己選擇的 Google 帳號，不會放到管理者或其他朋友的 Drive。管理者可選擇自助綁定後審核，或提供一次性邀請碼。

## 綁定

1. 加 Bot 為 LINE 好友，在私訊輸入 `綁定`；若管理者未啟用自助綁定，則向管理者私下取得有期限邀請碼並輸入 `綁定 你的邀請碼`。不要在群組貼邀請碼。
2. 預期 Bot 回覆一個約 10 分鐘有效的 Google Apps Script 連結。若在群組輸入，Bot 只會提醒你改用私訊，不會公開連結。
3. 開啟連結，先確認網域是 Google Apps Script，再按「前往 Google 授權」。在有效期限內重新整理此頁不會消耗綁定連結；同一 Google OAuth callback 不會重複完成綁定或重複扣除邀請次數。
5. 選擇要保存備份的 Google 帳號。權限應是基本帳號資料與 `drive.file`；不應要求讀取所有 Drive。
6. 按允許後，系統會先保留 Google 授權，再建立或重用備份資料夾與 Sheet。自助流程預期頁面顯示「Google 授權完成，等待管理者審核」；管理者核准後，回 LINE 輸入 `狀態` 才會顯示「Google 帳號：已綁定」。既有邀請碼流程仍會在資源完成後直接啟用。
7. 打開自己的 Google Drive，預期看到：

```text
LINE 自動備份/
├─ 個人備份/
├─ 群組備份/
└─ LINE 備份紀錄
```

## 日常使用

- 私訊圖片、影片、音訊或一般檔案：存入「個人備份／年／月／類型」。
- 私訊一般文字或網址：寫入「LINE 備份紀錄」Sheet。
- 在文字加入 `#旅遊`、`#收據` 等標籤，Sheet 的標籤欄會去重保存。
- 預設單檔上限是 20 MiB；管理者可調整，但提高到 45 MiB 屬高風險且不保證成功。超過時應看到安全拒絕訊息，Drive 不會建立檔案。
- 不要用 Bot 保存密碼、Recovery Code、身分證件或其他高度敏感資料。
- 自助綁定在審核前傳送文字、圖片或檔案時，Bot 會回覆「你的帳號尚未審核通過，請等待管理者核准。」且不會保存內容。

管理者可私訊 Bot 輸入 `待審核` 查看安全化代號；可用 `核准 1,2,3`／`拒絕 1,2,3` 批次處理指定編號。若要整批處理，先輸入 `核准全部` 或 `拒絕全部`，再由同一管理者於 5 分鐘內輸入回覆中的 `確認核准全部 <確認碼>` 或 `確認拒絕全部 <確認碼>`。整批結果會回覆成功、略過與失敗筆數。

## 解除綁定與撤銷

1. 私訊 Bot 輸入 `解除綁定`。預期回覆已清除 OAuth Token；既有 Drive 檔案不會刪除。
2. 再到 Google 帳號的「安全性」→「具有帳戶存取權的第三方應用程式」，找到此 App 並撤銷存取。預期 App 從允許清單移除。
3. 若你是群組 owner，解除個人綁定會同時停用你擁有的群組備份。
4. 要完全清除既有資料，請在自己的 Drive 手動刪除「LINE 自動備份」；刪除前先確認沒有仍需保留的檔案。

## 常見狀況

- 連結已失效：回 LINE 用仍有效的新邀請碼重新輸入 `綁定`。邀請次數只在 Google 授權與備份資源初始化全部完成後扣除；取消或初始化失敗不扣除。只有尚未授權且已過期的工作階段需要重新取得連結。
- Google 已授權但初始化失敗：不要重新消耗邀請碼。系統會保留 OAuth Token 與已建立的資料夾／Sheet；請把發生時間告知管理者，由管理者安全重試初始化。`狀態` 目前只查詢結果，不會自動恢復。
- 重複 callback 被拒絕：這是防重播保護。若 `狀態` 已顯示綁定成功，無須再操作；若初始化尚未完成，請管理者使用恢復功能，不要反覆點 callback 或重新發碼。
- Google 顯示 App 未驗證：確認 App 名稱與管理者提供的一致；若你不是 Test user，不要繼續，請管理者修正 OAuth 設定。
- 7 天後失效：Google OAuth App 仍在 Testing 且包含 Drive scope 時可能發生，請重新綁定並由管理者處理 Publishing status。
- 備份成功但沒收到回覆：所有指令都經 Queue 處理，Reply Token 可能在回覆前過期；先檢查自己的 Drive／Sheet，再告知管理者關聯時間。管理者即使啟用 Push fallback，也只會在 LINE 明確判定 Reply Token 無效時補送，並非每次都保證有訊息。
